## 笔记演进

```
初版（速览）→ 二版（深读）→ 三版（图表整理）→ 终版（交叉验证）
```

- **初版**：通读全书，记录核心知识和章节精华
- **二版**：逐章细读，记录具体数据、公式、图表编号、原书案例
- **三版**：用 Mermaid 整理流程图、时序图等可视化笔记
- **终版**：参考网络公开资料交叉验证，精简为可用的笔记
